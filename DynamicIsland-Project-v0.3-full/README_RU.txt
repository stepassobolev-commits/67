DYNAMIC ISLAND — проект для Windows 11 (v0.3)
=============================================
Как получить установщик (ничего не ставя на ПК):
1. Создайте новый репозиторий на github.com.
2. Загрузите в него ВСЁ содержимое этого архива (Add file -> Upload files, Ctrl+A).
3. Откройте Actions -> Build Windows installer -> Run workflow.
4. Через несколько минут скачайте DynamicIsland-Setup.exe из раздела Artifacts.

Возможности: капсула в стиле macOS, раскрытие при наведении, часы и дата,
управление музыкой (Spotify и другие плееры), обложка трека, громкость Windows,
буфер обмена с лимитом 5/10/20, закреплением, удалением, паузой и очисткой.
Выход: правый клик по капсуле -> "Закрыть Dynamic Island".
